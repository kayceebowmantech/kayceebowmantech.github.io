UNITY 3D

Froggy Forest

A small Unity 3D environment that started as a school project and became a personal project that I kept developing in my free time.

About the project

Froggy Forest began as a school assignment where I worked with Unity 3D and learned more about creating an environment. I liked the direction it was going, so I continued adding to it outside of class.

I wanted the environment to feel more like an actual scene rather than just a collection of models, so I spent time arranging the environment, lighting, plants, trees, paths, water, and other details to create the look I wanted.

What I did

I wrote the C# code myself and built the scene in Unity. I also handled the placement and organization of the environment and worked on the overall visual presentation.

The project uses free assets and models that I found online. I did not create those individual models myself, but I combined them and arranged them into the environment I wanted.

Technologies

C# Unity Visual Studio 3D Environment

What I learned

This project gave me more experience with Unity, C#, working with existing assets, and thinking about how individual visual elements work together as a complete scene.

It also showed me that I enjoy the combination of technical work and visual design that comes with game development.
