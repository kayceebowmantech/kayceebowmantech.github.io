UNITY 3D

Froggy Forest

A small Unity 3D environment that started as a school project and became a personal project that I kept developing in my free time.

About the project

Froggy Forest began as a school assignment where I worked with Unity 3D and learned more about creating an environment. I liked the direction it was going, so I continued adding to it outside of class.

I wanted the environment to feel more like an actual scene rather than just a collection of models, so I spent time arranging the environment, lighting, plants, trees, paths, water, and other details to create the look I wanted.

What I did

I wrote the C# code myself and built the scene in Unity. I handled the placement and organization of the environment and worked on the overall visual presentation.

I used free assets and models that I found online rather than creating the individual 3D models myself. I combined and arranged those assets to create the finished environment.

Technologies

C# Unity Visual Studio 3D Environment Design

What I learned

This project gave me more experience with Unity, C#, working with existing assets, and thinking about how individual visual elements work together as a complete scene.

It also helped me realize how much I enjoy combining programming with the visual and creative side of game development.

CODE

Selected code

I wrote C# scripts for player movement and mouse-controlled camera movement. The main focus of this project was creating and refining the visual environment in Unity.

Player Movement

float deltaX = Input.GetAxis("Horizontal") * speed;
float deltaZ = Input.GetAxis("Vertical") * speed;

Vector3 movement = new Vector3(deltaX, 0, deltaZ);
movement = Vector3.ClampMagnitude(movement, speed);

movement.y = gravity;
movement *= Time.deltaTime;

charController.Move(movement);

Mouse Camera Control

verticalRot -= Input.GetAxis("Mouse Y") * sensitivityVert;
verticalRot = Mathf.Clamp(verticalRot, minimumVert, maximumVert);

float delta = Input.GetAxis("Mouse X") * sensitivityHor;
float horizontalRot = transform.localEulerAngles.y + delta;

transform.localEulerAngles =
    new Vector3(verticalRot, horizontalRot, 0);
